2. Проблема

Проблема конечных пользователей, которую решает продукт.

- Сотрудник самостоятельно определяет нужный сервис для получения услуги: HelpMe, HR-сервисы, портал, Qlik

- Вынужденное переключение между несколькими интерфейсами

- Данные о сотруднике из корп. систем не переиспользуются при оформлении заявок

- Отсутствие единой логики работы с заявками: разные статусы, нейминг, системы

- Потребность в локальной автоматизации каждого сервиса/услуги

- Ландшафт интеграций усложняется с ростом систем/сервисов

3. Решение

3.1 Краткое описание

HR Agent Studio

Единое окно для получения HR-сервисов и услуг, которое объединяет пользовательский интерфейс, интеллектуальное сопровождение и интеграционный слой корпоративных систем.

AI HR-партнёр — выступает единым окном и управляет клиентским путём. Понимает задачу, сформулированную обычным языком, самостоятельно выбирает нужную услугу и сопровождает пользователя до результата. Определяет доступные операции, запрашивает недостающие сведения, соблюдает права и регламенты, а перед значимым действием получает подтверждение пользователя.

HR Hub — единый интеграционный модуль (ESB), через который HR-сервисы и информационные системы/AI агенты безопасно обмениваются данными. Он получает разрешённые сведения из действующих систем, обеспечивает предзаполнение заявок, передаёт команды на выполнение и возвращает единый статус результата.

Например, для оформления отпуска, командировки или справки сотрудник описывает задачу в одном окне, подтверждает подготовленное действие и получает единый номер заявки.

3.2 Предполагаемые конкурентные преимущества

  • HR Agent Studio выступает источника консолидированных данных не заменяя существующие системы
  • Лёгкое масштабирование: новые HR-сервисы и субагенты подключаются к единому контуру через HR Hub без перестройки всей системы и создания множества интеграций «каждый с каждым».
  • Агент определяет запрос сотрудника и самостоятельно выбирает сервис/услугу и доводит действие до результата
